XEVORAX REMODELING WEBSITE
============================

FILES
-----
index.html       Home page
services.html    Services page
projects.html    Projects/gallery page
project.html     Individual project details
about.html       About page
contact.html     Contact / estimate form
style.css        Complete styling + responsive mobile design
script.js        Navigation, cards, filtering, project details, form feedback and chatbot

HOW TO RUN
----------
1. Extract this folder.
2. Open the folder in VS Code.
3. Install the "Live Server" extension if you have not already.
4. Right-click index.html.
5. Choose "Open with Live Server".
6. The browser should open the website.
7. Test every navigation link and the project filters.

IMPORTANT
---------
The sample photos are loaded from Unsplash URLs, so internet access is needed for the photos and Google Fonts.
The contact form is FRONT-END ONLY. It shows a success message but does not send email yet.
To make the form actually send submissions, connect it to a backend, Formspree, EmailJS, Netlify Forms, or your own API.

CUSTOMIZE BEFORE A REAL CLIENT DELIVERY
---------------------------------------
- Replace Xevorax with the client's real brand.
- Replace phone, email and address.
- Replace sample project descriptions and photos.
- Connect the contact form to a real submission service/backend.
- Add the client's real logo.
- Test the site on phone, tablet and desktop.
